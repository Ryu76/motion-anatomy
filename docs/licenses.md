# Licenses

## Production anatomy assets

The web viewer includes derived, Draco-compressed GLB reference systems from:

- **Z-Anatomy — The open source atlas of anatomy**: CC BY-SA 4.0
- **BodyParts3D — The Database Center for Life Science**: CC BY-SA 2.1 Japan

Distributed derivatives:

- `apps/web/public/models/z-anatomy/z-anatomy-muscular-system.glb`
- `apps/web/public/models/z-anatomy/z-anatomy-skeletal-system.glb`

The source FBX files are not shipped. Reproducible conversion is documented in `scripts/convert_z_anatomy.py`. Full attribution, source URLs, modification notes, and license links are preserved in `apps/web/public/models/z-anatomy/ATTRIBUTION.md` and attribution is displayed in the application footer.

The dynamic gluteus maximus and rectus femoris fiber overlays are original project code. They are functional anatomy simulations and are not validated for diagnosis or treatment planning.

## Asset review checklist

Before another asset enters production, record commercial use, attribution, modification, redistribution, source-file exposure, derived render rights, and share-alike obligations. Legal and anatomy review must be marked approved.
