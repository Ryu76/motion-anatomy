# Z-Anatomy model attribution

The anatomical reference meshes in this directory are adapted from:

- **BodyParts3D — The Database Center for Life Science** — CC BY-SA 2.1 Japan
- **Z-Anatomy — The open source atlas of anatomy** — CC BY-SA 4.0
- Source repository: https://github.com/LluisV/Z-Anatomy
- Source files: `Resources/Models/FBX/MuscularSystem100.fbx`, `SkeletalSystem100.fbx`, `Joints100.fbx`, and `CardioVascular41.fbx`

The web derivatives are separated by anatomical system, geometry-decimated, and Draco-compressed for interactive rendering. The detailed muscle derivative adds project-authored `Shorten` and `Lengthen` morph targets to the original gluteus maximus and rectus femoris vertices while pinning the attachment ends. The adapted model assets remain available under CC BY-SA 4.0. Application source code is governed separately by the repository license.
